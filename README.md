# 方块星球 · Block Planet

一个使用 React 19、Three.js、WebGL、Vinext、Node.js 与 Bun 构建的第一人称体素生存游戏。关卡由真实三维方块组成，并使用程序化像素贴图、动态光照和本地世界存档。

## 运行环境

- Node.js >= 22.13（当前已验证 v24.19.0）
- Bun（当前已验证 v1.3.14）

## 本地运行

```bash
npm install
npm run dev
```

开发服务监听 `0.0.0.0:7897`。也可以使用 Bun 启动：

```bash
bun run dev
```

本机固定入口为 `http://localhost:7897/`。项目附带 macOS 自动保活配置；
局域网 IP 发生变化时，本机入口仍然保持不变。

如果本机自动服务没有运行，可双击 `deploy/start-local.command`，脚本会启动服务并自动打开游戏页面。

生产构建：

```bash
npm run build
```

## 操作

- 点击游戏画面：锁定鼠标视角
- 移动鼠标：环顾三维世界
- 鼠标锁定不可用时：按住左键拖动视角
- 左键：破坏准星选中的方块
- 右键：在选中方块表面放置方块
- 数字键 `1–9`：切换快捷栏材料
- `WASD`：第一人称移动
- `Space`：跳跃
- `Shift`：疾跑
- `E`：打开物品栏
- `L`：打开任务日志
- `T`：切换白天、黄昏与夜晚
- `Esc`：打开游戏菜单

基础机制包括连续移动、鼠标视角、跳跃、重力、地形碰撞、方块射线检测、破坏与放置、九格快捷栏、资源数量、章节任务、昼夜光照和设备本地存档。晨曦山谷关卡包含河流、山地、森林、橡木庇护所、营火、花丛和方块动物。
